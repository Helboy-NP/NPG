# Rencana Fitur NP Store

Fitur yang direncanakan untuk proyek ini:
1. Pencatatan penjualan dan transaksi.
2. Pengelolaan persediaan/stok.
3. Daftar harga barang.
4. Pembuatan dan penyimpanan nota.
5. Pencatatan kartu garansi.
6. Laporan penjualan dan keuntungan.
7. Penyimpanan data — pilihan backend/database akan ditentukan sebelum integrasi.

Catatan: dokumen ini adalah daftar kerja awal. Rincian tampilan dan perilaku tiap fitur perlu disepakati sebelum implementasi.
